# Yandex Intelligence

`yandex_intelligence` объединяет два независимых источника доказательств:

- фактические данные подтверждённого сайта из Яндекс Вебмастера;
- сохранённые ответы YandexGPT, полученные штатным Research Pipeline.

Сервис не эмулирует Алису и не извлекает данные из пользовательского интерфейса
Яндекса. Раздел «Видимость в Алисе AI» может быть добавлен только через
официальный документированный API или пользовательский экспорт.

## Поток данных

1. `POST /yandex-intelligence/sync` получает запросы, целевые URL, показы,
   клики, CTR, позиции, диагностику, индексирование, внешние ссылки и Sitemap.
2. Сервис находит ответы YandexGPT для того же сайта и сопоставляет их с
   неизменными запросами.
3. Версионированный алгоритм `1.0` строит карту `запрос → страница → ответ ИИ`
   и приоритеты. Поисковые факты не выдаются за доказанную причину ответа ИИ.
4. Результат сохраняется как неизменяемый snapshot и доступен через
   `GET /yandex-intelligence/dashboard`.
5. `GET /yandex-intelligence/query-seeds` предоставляет публичный read-only
   порт оркестратору исследований. Мастер автоматически добавляет до восьми
   реальных запросов Вебмастера, если пользователь не задал собственные.

## Статусы доказательности

- `MEASURED` — есть данные Вебмастера и сопоставленный ответ YandexGPT;
- `PARTIAL` — присутствует только один из источников;
- `NOT_MEASURED` — подходящих наблюдений нет.

Рекомендации содержат исходный запрос, наблюдаемые значения, целевую страницу,
действие, уровень уверенности и способ повторной проверки. Рост позиции или
AI Visibility не гарантируется.
