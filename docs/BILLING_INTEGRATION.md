# Подключение оплаты

## Решение для первого релиза

Для российского B2B SaaS основной провайдер — ЮKassa. Интеграция выполняется через
официальный REST API из backend-модуля `billing`, без передачи платёжных секретов во
frontend. Официальный Python SDK существует, но его открытый репозиторий переведён в
архив, поэтому ядро продукта не должно зависеть от него.

- API: https://yookassa.ru/developers/api
- Webhooks: https://yookassa.ru/developers/using-api/webhooks
- Аутентификация и идемпотентность:
  https://yookassa.ru/developers/using-api/interaction-format
- Официальный SDK: https://github.com/yoomoney/yookassa-sdk-python

CloudPayments можно держать вторым адаптером: он поддерживает рекуррентные платежи,
но официального поддерживаемого серверного Python SDK в открытых репозиториях не
найдено. Документация: https://developers.cloudpayments.ru/

## Контракт модуля

1. `POST /billing/checkout` создаёт платёж с уникальным ключом идемпотентности и
   возвращает только URL подтверждения.
2. `POST /billing/webhooks/yookassa` принимает событие, затем backend повторно
   запрашивает состояние платежа у ЮKassa. Данные webhook не считаются доверенными
   без этой проверки.
3. `GET /billing/subscription` возвращает тариф, лимиты и дату следующего списания
   текущей организации.
4. `POST /billing/subscription/cancel` выключает автопродление, не удаляя уже
   оплаченный доступ.

## Изоляция и безопасность

- подписка принадлежит `organization_id`, а не отдельному пользователю;
- `shop_id` и секрет хранятся только в переменных окружения/хранилище секретов;
- в БД сохраняются идентификаторы провайдера, суммы, валюта и статусы, но не данные
  банковской карты;
- на `(provider, external_payment_id)` и ключ идемпотентности ставятся уникальные
  ограничения;
- выдача лимитов происходит только после подтверждённого статуса `succeeded`;
- все изменения подписки записываются в аудит.

## Следующий шаг

Для рабочего checkout нужны `shop_id`, секретный ключ ЮKassa, выбранные тарифы и
публичный URL webhook. До получения этих данных нельзя безопасно включать реальные
списания.
