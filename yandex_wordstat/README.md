# Yandex Wordstat integration

Основной источник реального поискового спроса для исследования видимости в экосистеме Яндекса.

1. Администратор организации сохраняет Folder ID и API-ключ с областью `yc.search-api.execute` либо IAM-токен сервисного аккаунта с ролью `search-api.webSearch.user`.
2. `POST /integrations/yandex-wordstat/discover` получает частотные и похожие запросы через официальный Yandex Search API `/v2/wordstat/topRequests`.
3. Неизменяемый snapshot хранит запрос, частотность, ранг, регион, устройство и версию алгоритма.
4. Research Wizard добавляет до 12 самых частотных небрендовых запросов к следующему исследованию.
5. `GET /integrations/yandex-wordstat/analytics` сопоставляет их с сохранёнными ответами YandexGPT.

Wordstat измеряет спрос в Яндекс Поиске, а не в Алисе. YandexGPT используется как отдельный измерительный канал; продукт не утверждает, что его ответы полностью совпадают с публичной Алисой.
