# GEO Site Audit

Evidence-based website readiness audit for generative search. Version 1.0 evaluates 100
points across crawlability, entity clarity, content, evidence and technical readiness.
Every point is traceable to an observed page signal. The score does not claim that a
closed AI model indexed the site or that one change will cause a recommendation.

API: `POST /geo/site-audits`, `GET /geo/site-audits`, `GET /geo/site-audits/{id}`.
